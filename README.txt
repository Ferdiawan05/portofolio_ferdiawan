# Portfolio Ferdiawan
Website portfolio responsive berdasarkan isi Portofolio Ferdiawan 2026.

## Cara menjalankan
1. Extract folder.
2. Buka `index.html` di browser.
3. Tidak membutuhkan database atau server.

## Catatan
Bagian foto profil dibuat sebagai placeholder huruf F agar tidak mengarang foto. Ganti area tersebut dengan foto Anda jika diinginkan.
